## 🎯 功能概览

TG Bot Manager Web管理后台是一个**现代化、响应式**的管理界面，提供以下核心功能：

### ✨ 核心特性

- **📊 实时仪表板**：系统状态一目了然

- **🏢 租户管理**：多租户支持，隔离数据

- **📝 系统日志**：完整的操作审计日志
- **⚙️ 系统设置**：配置系统参数

### 🎨 界面特点

- **现代化UI**：基于Bootstrap 5设计
- **响应式设计**：支持桌面和移动设备
- **暗色侧边栏**：专业的管理界面风格
- **实时更新**：自动刷新统计数据
- **操作友好**：直观的交互体验

## 🌐 代理管理

**路径**: `/admin/proxies`

### 功能

#### 1. 查看代理列表

显示所有已添加的代理，包括：
- 代理类型（MTProto、SOCKS5、HTTP）
- 服务器地址
- 端口号
- 密钥信息（部分显示）
- 在线状态

#### 2. 添加代理

**支持的代理类型**：

##### MTProxy（推荐）

```
格式: https://t.me/proxy?server=SERVER&port=PORT&secret=SECRET

示例:
https://t.me/proxy?server=1.2.3.4&port=443&secret=ee38df3159cdeec7bf5122293ab5c28c
```

**特点**：
- ✅ 速度最快
- ✅ 伪装成HTTPS流量
- ✅ Telegram官方协议

##### SOCKS5

```
格式: socks5://[user:pass@]SERVER:PORT

示例:
socks5://127.0.0.1:1080
socks5://user:pass@proxy.example.com:1080
```

**特点**：
- ✅ 通用性强
- ✅ 支持用户名密码认证

#### 3. 删除代理

点击"删除"按钮即可移除代理，系统将：
- 从代理池中移除
- 记录操作日志
- 刷新页面显示

#### 4. 测试代理（开发中）

未来将支持：
- 一键测试代理连接
- 显示延迟和速度
- 自动标记离线代理

### 代理使用说明

1. **添加代理后**，系统会自动将其加入代理池
2. **轮询使用**：每次创建客户端时轮询获取下一个代理
3. **无代理模式**：如果代理池为空，系统使用直连模式
4. **动态管理**：可随时添加或删除代理，立即生效

### 最佳实践

```python
# 推荐配置
1. 优先添加MTProxy代理（速度快、稳定）
2. 准备3-5个不同地区的代理备用
3. 定期测试代理可用性
4. 批量操作时轮询使用不同代理
```

## 🏢 租户管理

**路径**: `/admin/tenants`

### 功能

#### 1. 查看租户列表

显示所有租户信息：
- 租户代码（唯一标识）
- 租户名称
- 许可证类型
- 账号配额
- 会话配额
- 过期时间
- 当前状态

#### 2. 创建新租户

点击"创建租户"按钮，填写：

- **租户代码**：唯一标识（如：TENANT001）
- **租户名称**：公司或组织名称
- **许可证类型**：
  - 试用版（Trial）
  - 月付版（Monthly）
  - 年付版（Yearly）
  - 永久版（Lifetime）
- **最大账号数**：允许管理的账号上限
- **最大TGAPI会话数**：允许创建的接码会话上限

**创建成功后**：
- 自动生成许可证密钥
- 显示许可证密钥（请妥善保存）
- 记录创建日志

#### 3. 许可证类型说明

| 类型 | 特点 | 适用场景 |
|------|------|----------|
| **试用版** | 短期使用，功能限制 | 新用户试用 |
| **月付版** | 按月付费，灵活 | 小规模使用 |
| **年付版** | 按年付费，优惠 | 中等规模使用 |
| **永久版** | 一次付费，永久使用 | 大规模长期使用 |

#### 4. 租户隔离

每个租户的数据完全隔离：
- 账号数据
- TGAPI会话
- 操作日志
- 配额管理

## 🔗 TGAPI会话管理

**路径**: `/admin/tgapi-sessions`

### 功能

#### 1. 查看会话列表

显示最近100个TGAPI会话：
- 会话ID
- API Token
- API URL（接码链接）
- 登录次数 / 最大登录次数
- 会话状态
- 过期时间
- 创建时间

#### 2. 会话状态

| 状态 | 说明 | 操作 |
|------|------|------|
| **活跃** | 会话可用 | 可禁用 |
| **已过期** | 超过过期时间 | 只读 |
| **已禁用** | 管理员禁用 | 只读 |

#### 3. 禁用会话

点击"禁用"按钮：
- 立即停止会话
- 阻止新的登录请求
- 记录操作日志

### TGAPI会话说明

**什么是TGAPI会话？**

TGAPI会话是将Telegram账号转换为在线接码链接的核心功能：

```
1. 服务端持有Telegram账号Session
2. 生成唯一的API Token和URL
3. 客户端通过URL获取验证码
4. 实现账号接码功能
```

**使用场景**：
- 远程登录Telegram账号
- 自动化账号管理
- 批量账号操作

## 🔐 许可证管理

**路径**: `/admin/licenses`

### 功能

#### 1. 查看许可证列表

显示所有租户的许可证信息：
- 租户代码
- 租户名称
- 许可证密钥（完整显示）
- 许可证类型
- 过期时间
- 当前状态
- 创建时间

#### 2. 许可证密钥

格式：`TENANT-XXXX-XXXX-XXXX`

**特点**：
- 唯一性保证
- 机器绑定（最多3台设备）
- 硬件指纹验证
- 防止盗版

#### 3. 许可证验证流程

```
1. 客户端提交 license_key + machine_id
2. 服务端验证许可证有效性
3. 检查设备绑定数量
4. 验证过期时间
5. 返回验证结果
```

### API接口

```bash
# 验证许可证
POST /api/license/validate
{
    "license_key": "TENANT-XXXX-XXXX-XXXX",
    "machine_id": "unique_machine_id"
}
```

## 🔒 安全特性

### 1. 认证系统

- **Session-based认证**
  - Cookie存储Session ID
  - HttpOnly防止XSS攻击
  - 24小时自动过期

- **密码哈希**
  - SHA256哈希存储
  - 不存储明文密码

### 2. 访问控制

- **路由保护**
  - 所有管理路由需要认证
  - 未登录自动跳转登录页
  - Session失效自动登出

- **CORS配置**
  - 跨域请求控制
  - 可配置白名单

### 3. 会话管理

- **自动清理**
  - 每小时清理过期会话
  - 防止内存泄漏

- **单点登录**
  - 同一账号多设备登录
  - Session独立管理

### 4. 操作审计

- **完整日志**
  - 所有管理操作记录
  - 包含操作者、时间、结果
  - 便于事后审计

## ❓ 常见问题

### Q1: 忘记管理员密码怎么办？

目前默认密码是 `admin123`。未来版本将支持密码重置功能。

### Q2: 管理后台支持多用户吗？

目前支持单个管理员账号。未来版本将支持多管理员和权限系统。

### Q3: 代理添加后立即生效吗？

是的！代理添加到池中后立即可用，无需重启服务。

### Q4: 如何修改会话超时时间？

当前会话超时时间固定为24小时。未来版本将支持在系统设置中修改。

### Q5: 管理后台支持HTTPS吗？

建议在生产环境使用Nginx反向代理，并配置SSL证书。
